# Menekşe Medreseleri – Web Sitesi

Menekşe İlim Kültür Okuma Derneği için `menekseilim.com.tr` adresinde
yayınlanacak statik web sitesi (HTML, CSS, JS; iletişim formu için küçük bir
PHP betiği).

* Yayına alma, eksik bilgiler ve düzenleme: **[YAYINLAMA_REHBERI.md](YAYINLAMA_REHBERI.md)**
* Sayfaları üreten betikler depo kökündeki `menekseilim-kaynak/` klasöründe:
  `olustur.py` (sayfalar) ve `logo_uret.py` (logo dosyaları).
* cPanel'e yüklemeye hazır paket: depo kökündeki `menekseilim-site.zip`.
  Dosyaları değiştirirseniz ZIP'i yeniden oluşturun.
