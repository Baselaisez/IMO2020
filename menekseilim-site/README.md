# Menekşe İlim Kültür ve Okuma Derneği – Web Sitesi

`menekseilim.com.tr` için hazırlanmış, bağımlılığı olmayan statik web sitesi
(HTML, CSS, vanilla JS; iletişim formu için küçük bir PHP betiği).

* Yayına alma adımları (hosting, DNS, SSL, GitHub Pages, form ayarı):
  **[YAYINLAMA_REHBERI.md](YAYINLAMA_REHBERI.md)**
* Yerelde görüntülemek için `index.html` dosyasını çift tıklamanız yeterlidir.
  (Form gönderimi yalnızca PHP çalıştıran bir sunucuda çalışır.)
* cPanel'e yüklemeye hazır paket: deponun kökündeki `menekseilim-site.zip`
  (bu klasörün rehber ve README dışındaki içeriği). Dosyaları değiştirirseniz
  ZIP'i yeniden oluşturun.

Köşeli parantez içindeki `[...]` değerler ve `img/yer-tutucu.svg` görselleri,
yayından önce gerçek bilgilerle değiştirilmesi gereken yer tutuculardır.
